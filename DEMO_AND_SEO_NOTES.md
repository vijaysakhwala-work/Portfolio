# Cubusify demo update

Five main interactive experiences at /demo-studio: Ecommerce, Fitness, Snake, CRM, WhatsApp + Sheets. Previous embedded mini-demos now link into these five experiences. All data is session-only; no payments, outbound WhatsApp messages or Google Sheets credentials are used. Real integrations require backend services and credentials.

Interface previews in service, AI and industry detail sections now use real HTML text instead of enlarged raster lettering. The service directory, AI overview and app/software/automation portfolio details also use crisp interface previews. Existing photography and photography-led website artwork are retained; these are not regenerated originals.

Demo interactions load in a separate route chunk. Static pages retain prerendered HTML, canonical links, metadata, sitemap and service structured data. No new external runtime dependency was added.

## SEO priorities

1. Replace broad repeated service copy with useful service-specific deliverables, integration options, timelines and FAQs. Focus each page on an actual customer question.
2. Add real case studies with permission: problem, scope, approach and verified outcomes. Keep conceptual portfolio work clearly labelled.
3. Publish focused guides for customer searches, e.g. WhatsApp enquiry automation with Google Sheets, custom CRM costs and ecommerce integration planning. Link each guide to the appropriate service.
4. Connect Google Search Console after deployment, submit the sitemap and review index coverage and search queries.
5. Measure the deployed site with PageSpeed Insights and field Core Web Vitals; a local build size is not a real-world speed score.
6. Audit unverified metrics and testimonials before publishing. Trust depends on accurate claims.
